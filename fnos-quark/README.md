# 飞牛夸克下载器 (fnos-quark)

飞牛夸克下载器是一款面向飞牛 fnOS 的夸克网盘第三方工具，可在网页中浏览网盘，并将有权访问的文件下载到 NAS。需要 fnOS `1.1.8` 或更高版本。

> ⚠️ 本项目是非官方第三方工具，与夸克网盘及其运营方不存在隶属、合作或授权关系。本工具不提供网盘限速破解、绕过访问控制或未授权访问等功能。实际下载速度由夸克官方服务、账号权益和网络环境决定。为防止滥用，暂不提供 docker 版本。

## 主要功能

- 浏览夸克网盘文件夹，并按名称、大小或更新时间排序
- 下载单个文件或整个文件夹，可选择是否保留网盘原始路径
- 查看任务状态、文件进度、实时速度和预计剩余时间
- 支持暂停、继续、断点续传、优先下载和取消下载
- 支持 1–5 个文件并发下载，默认 3 个
- 单文件可选择 1、2、3、4 或 6 条标准 Range 分片连接
- 可在“下载设置”中切换 fnOS 已授权且可写的下载目录
- 支持同名文件策略、硬盘保留空间、总下载限速和下载时段
- 访问令牌验证默认开启，可在可信内网关闭
- 普通浏览器和飞牛 App 均可记住验证状态
- 硬盘空间不足或 Cookie 失效时自动暂停，条件恢复后可继续
- 提供任务通知、日志查看、异常筛选和脱敏诊断包
- 网页适配桌面、平板和手机

## 安装

1. 打开 GitHub Releases 页面：https://github.com/ElyDemiurge/fnOS-quark/releases
2. 下载与设备架构相符的 `.fpk` 安装包
3. 在 fnOS“应用中心”中选择手动安装并上传安装包
4. 安装完成后，从 fnOS 桌面打开“飞牛夸克下载器”
5. 阅读并同意使用协议，按照页面提示完成访问令牌和 Cookie 设置

## 数据目录

应用数据位于 `应用文件/fnos-quark`：

```
fnos-quark/
├── config/       Cookie、访问令牌设置和下载设置
├── data/         下载任务与通知记录
├── downloads/    下载结果
├── logs/         运行日志
└── runtime/      进程运行状态
```
